# My Dotfiles

These are my dotfiles for my Arch, MacOS and Work (Fedora Linux 42 running on WSL) setup. My dotfiles are managed using Chezmoi.

## Requirements
- Install [Chezmoi](https://www.chezmoi.io/) on your system.
- Create a file in `.config/chezmoi/chezmoi.toml` and fill in the following fields:

```toml
[data]
email = "your@email.here"
```
